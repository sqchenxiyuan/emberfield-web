# 饮食政策与手动食用

本轮把食物生产接到实际分配：**共享饮食政策 → 选择真实食物 → 步行取食或送餐 → 用餐/喂食 → 消耗同一批食物**。玩家可以指定临时食用命令。先完成选择、中断、物品守恒和存读闭环；营养、饥饿速度、优先顺序和咀嚼时间继续作为可调参数。原版依据见 [157 饮食政策静态机制](157-food-policies-mechanisms.md)。

## 玩家操作

选中居民或囚犯后，在需求区设置饮食政策。政策允许选择简餐、口粮、奶、未受精蛋、谷物、肉和受精蛋，可新建、复制、改名、编辑后保存，或给人物选择“不分配限制”。同一政策的修改共同影响所有使用者；被人物引用的政策不能删除，死亡人物的引用也会保留。至少一份、最多十六份政策，名称最多四十字。

新营地默认分配允许全部七类食物的共享政策。旧存档不自动绑定政策，继续原来的自由取食，玩家可以再分配。食物不必位于仓库：只要符合现有可食、可达、权限、区域和预约条件，散落在地上的食物也可取用。

选中地面食物，可选择可行动居民并点击“前往食用”。该次命令覆盖饮食政策，解除这堆食物的禁止取用，并允许选择当前允许区域外的目标。居民实际走到食物旁、拿取或原地进食、花时间咀嚼，完成后才扣除实物并补充饱食度。政策本身保持原值。已吃饱、征召、倒地、被携带或精神失常的居民无法接受此命令。

## 机制连接

| 情况 | 行为 |
|---|---|
| 自行进食 | 用进食者的政策筛选地面及随身食物；携带食物不自动豁免 |
| 医生/狱卒喂食 | 按被喂食者的政策选餐；送餐者自己的政策不决定患者吃什么 |
| 囚犯自行取食 | 不受供餐政策限制，仍受牢房活动边界和实际食物位置约束 |
| 饥荒 | 不自动解除政策；没有允许的食物时保留限制 |
| 精神状态 | 原版政策判断有精神状态豁免；Web 已接入该判断，但未因此增加精神失常居民自动寻找食物的完整行为 |
| 自动取食/用餐/喂食途中改政策 | 立即取消不再允许的任务，释放预约，已携带食物保留 |
| 手动食用途中改政策 | 本次显式食用继续；之后的自动进食按新政策执行 |
| 玩家重新指定允许区域或重新禁止食物 | 按目标和活动状态取消失效任务；保留已取物资 |
| 两人竞争同一堆 | 共享实际堆的剩余数量与预约，不重复领取同一份食物 |
| 双手装满且地面没有卸货空间 | 非食物货物可留在手中、预约脚下食物原地吃；已有另一批食物时先等待安全卸货，避免丢失或混淆两批食物 |
| 用餐被征召等中断 | 取消本次任务和座位预约，未吃下的批次继续保留数量与中毒信息 |

受精蛋仍沿用已有自动地面取食的饥荒门槛；政策允许它不意味着普通自动选择一定优先吃它。手动命令可以明确指定该食物。物品腐败、孵化、禁止或其他来源变化仍走现有任务失效和物资处理流程。

## 与原版的边界

原版限制针对最终食物定义及特殊过滤器。这里是七类现有物资的筛选；禁止生肉不会自动禁止含肉简餐，简餐当前没有原料来源追踪，因此不宣称支持素食、食人禁忌、宗教食规或完整默认餐食等级库。动物没有接入居民饮食政策。

原版普通囚犯送餐会把食物放进牢房，卧床者使用喂食任务。Web 沿用已有的直接喂食流程，健康囚犯送餐也由狱卒到场完成；这一差异尚待后续扩展。原版正在运行的 Ingest/FeedPatient/FoodDeliver 没有直接逐帧重读政策；这里政策修改后立即撤销不合规自动任务属于管理一致性适配。

手动食用的政策和区域目标豁免有静态证据；Web 禁止满饱食度下单、允许玩家再次禁止物品来中断任务，以及满手物资的处理属于本游戏规则。原版手动任务允许区外目标，但路径仍可能保留区域偏好；不能把两者说成完全相同的寻路行为。

## 存档与验证

存档升级至 **v57**，保存共享政策、人物引用，以及进行中的显式食用身份。取食阶段保存来源堆 ID，用餐阶段保存实际随身批次或原地食物与咀嚼进度；读档重建路径和预约。旧版本只增加默认政策库和空人物引用，不虚构手动命令，也不修改旧衣物政策、生产账单或物资。旧版本夹带新字段、失效引用及不一致任务会被拒绝。

机制验证采用受控地形、无界面真实模拟 tick、SSR 与命令处理检查；这些夹具用于隔离机制，不代表自然新营地的人工试玩。另使用已发布 v56 的真实烹饪与布帽制作中间存档，与精确 Git 构建的旧引擎逐 tick 对照，并反复存读。只归一化严格验证过的新增默认政策字段和版本号，保留旧服装状态参与完整比较。

最终测试、静态提取、历史续跑及构建的文件身份记录在 [验证回执](evidence/food-policies-voxel-validation.json)，本地复核入口为 `node scripts/research/verify-voxel-food-policies-validation.mjs --local`。

按每个文件最新完整结果，本地共 **154 个测试文件、2,022 项检查通过**。全量首轮为 2,020/2,022：一项环境/贸易检查超过原 20 秒限制，另一项是已定位的商队模板继承临时取食命令问题；后者已修复，相关手动食用和贸易整文件 17/17 通过，两份最后受影响文件在单 worker、原超时限制下完整复跑 15/15 通过。早期整合夹具的座位占用和袭击者身份问题也已修正，全部尝试报告保留，不拼接单个成功断言。最终类型检查、构建及回执冻结/复核通过。

真实 v56 历史续跑共 **750 tick、756 次完整存档比较、5 次重载**，完成一餐和一顶布帽，实物与材料守恒；复跑绑定商队修复后的源码。原版静态核验覆盖 37 类型、123 锚点、17 限定方法检查、16 XML 投影和 8 食物继承链。本轮没有将数值参数调整为平衡定稿。

本轮不运行或交互操作原版、浏览器、预览或其他 GUI。发布后使用原始 HTTP 核对页面和构建文件；这只证明发布字节一致，不能替代画面或操作手感验收。发布流水线继续只安装、构建和部署，测试留在本地。
