# 服装政策：自动取衣、换装与强制穿戴

这轮把制衣成果接入居民日常管理：**共享服装政策 → 从真实储存区找衣服 → 步行取用 → 花时间更换 → 旧衣落地并由搬运工作收纳**。先完成可操作的机制、任务中断和存档衔接；护甲权重、保暖倾向与检查间隔作为后续调参起点。原版静态依据见 [155 服装政策机制](155-apparel-policies-mechanisms.md)。

## 玩家操作

在居民的衣着面板分配“自由穿戴”或自建共享政策，也可以选择“手动管理”。新营地居民默认自动管理；升级的旧营地保留手动模式，可自行启用。

政策支持名称、允许的七种衣物、品质上下界和耐久百分比上下界。复制一份政策后可分别用于日常工作或护甲配置；编辑先留在面板草稿中，保存后共同影响分配它的居民。至少保留一份、最多十六份；仍被人物引用的政策不能删除，包括死亡人物保留的引用。政策没有独立的材质筛选。

手动命令居民穿衣会在实际穿好后加上“强制穿戴”标记。自动政策不会脱掉它，也不会用冲突的衣物替换它；玩家仍可手动替换或脱下。可以单件或全部解除强制，解除时衣物继续留在身上，之后才按政策处理。

自动候选必须位于接纳该衣物的地面储存区或货架。散落在野外的战利品需要先入库，或由玩家手动命令取穿。新衣服进入仓库后，居民会在下一次检查时考虑；修改政策或重新分配政策会唤醒检查。

## 实际规则

| 条件 | 当前行为 |
|---|---|
| 身上有政策不允许的衣物 | 优先脱下非强制衣物，再寻找替代 |
| 衣物禁止、起火、在允许区域外、缺少可穿部位 | 不作为自动候选；自动取衣没有手动指令的区域豁免 |
| 衣物已被其他人换装或搬运预约 | 不争抢；实际堆与任务共用实体身份 |
| 没有可达候选 | 按确定性的 6000–9000 模拟 tick 间隔再检查，避免每帧扫描 |
| 存储衣物有更高收益 | 前往可交互位置，实际拿到手中，再累计装备时间 |
| 冲突衣物无法落地 | 当前穿戴与携带的新衣都保留，等待周边腾出空间 |
| 政策、允许区域或物品权限在途中改变 | 重新核对任务；不再允许的自动任务取消，已携带衣物保留 |
| 饥饿、医疗、睡眠、征召等打断 | 沿用既有需求和工作中断流程；不凭空装备、不复制衣物 |
| 强制衣物损坏、被手动脱下或替换 | 清除失效标记；不会留下不存在的衣物引用 |

评分使用现有材质与品质产生的护甲、保温属性，并加入耐久评分。替换收益扣除全部冲突旧衣得分；空闲穿戴层有加成。寒冷时按当前五天季节段的室外平均气温提高保暖权重，避免居民在室内外频繁切换时反复换衣。依据原版已核实的这段规则，炎热季节没有对称的隔热加成；不把这一规则宣传为完整冷热最优解。

## Web 适配与尚未实现部分

原版以自身季节系统、完整人体和服饰数据评分。本实现使用已有的七种衣物、三种材料及身体部位模型，季节均温复用 Web 气候采样。只在需求与携带物资处理后、普通工作分配前检查服装；不会为了扫描政策持续打断生产任务。

原版 Wear 会先实际丢下冲突旧衣；这里沿用已有的原子落地规划，所有旧衣有位置才提交换装，以保住拥堵空间内的物资。政策修改后取消不再合规的活动自动任务，是本游戏的一致性处理，不能称为原版 Wear 每帧重读政策。原版独立脱衣任务可以接着搬运脱下的衣物；这里交给普通搬运工作，禁用搬运时旧衣会留在地上。

尚未实现衣物污染与厌恶思想、人皮偏好、身份衣着要求、locked 锁定衣物、DLC 奴隶/机械师/真空等专用规则，以及原版完整默认政策库。该阶段没有进行全局平衡或完整原版服饰系统验收。

## 存档与验证

存档升级到 **v56**，保存共享政策、居民政策引用、强制衣物 ID 和下一次检查时间；自动换装任务带明确标记。旧档只补默认政策集合和手动控制状态，不改原有衣物、进度或过去的命令。新字段、重复身份、失效引用、非法筛选和伪装旧版本注入都会校验。

无界面专项测试涵盖真实取衣与装备、获取及装备阶段回读、旧衣落地、共享政策移除、手动强制及解除、两人竞争、搬运预约、禁止和区域变更、季节选择、扫描退避、非法命令与存档。受控地形和衣物夹具用于隔离机制，不作为自然新营地经营验收。

真实历史验证从已发布 v55 的烹饪与布帽制作中间存档继续，与精确 Git 构建的 v55 普通续跑逐 tick 比较完整存档。750 tick、5 次回读和 756 次完整状态审计通过；只允许版本及严格检查后的新增默认政策/manual 控制字段不同。继续完成一份饭、一顶布帽，原材料和物品身份保持一致。

最终本地测试、构建、静态研究和历史续跑的源文件/产物哈希统一记录在 [验证回执](evidence/apparel-policies-voxel-validation.json)。复核命令为 `node scripts/research/verify-voxel-apparel-policies-validation.mjs --local`。它读取保留的证据，不重新运行全部测试。

按每个文件最新完整结果，本地回归共 **150 个测试文件、1,962 项检查通过**。首轮出现人工改派系夹具未补服装控制字段、历史迁移预期未补新增默认字段，以及高并发超时。修正夹具后五份完整文件 72/72 通过；七份超时或受影响文件在原超时限制下单 worker 完整重跑 96/96 通过。首次报告全部保留，未拼接单个成功断言或放宽校验。最终类型检查、构建与冻结回执复核也通过。

本轮没有启动或交互操作原版游戏、浏览器、预览或 GUI。SSR 和无界面模拟验证不代表 GPU 画面、面板操作手感或人工试玩验收。发布流水线仍只安装、构建和部署；测试在本地运行。
