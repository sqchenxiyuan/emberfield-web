# 动物训练与实际协作

本轮优先接通“取得犬 → 备粮训练 → 学会能力 → 参与殖民地工作 → 中断与保存继续”。原版依据见 [161 静态机制](161-animal-training-mechanisms.md)。训练时间、成功率、食量、贸易价格、攻击伤害与调度间隔均为集中定义的初值，尚未做平衡校准。

当前为 v59 实现与无界面验证记录；界面画面、操作手感和自然新开局的完整养犬过程仍需后续交互验收。

## 玩家操作与结果

综合商队增加真实公母拉布拉多犬，沿动物通路跟随商队入场；购买后保留同一个体的年龄、健康、饥饿与训练状态。新出生犬没有父母的训练成果。犬可以吃现有粮食、肉、奶、蛋和制成食品，不会从地上草丛或活作物获得营养。其活动范围使用非圈养动物的允许区域，无需牵入家畜圈。

动物详情与动物总览增加训练设置。玩家勾选训练意愿，开启居民的驯养分工并提供可达的原始食物；饲养员取走实物、接近犬、面对面训练并分两次喂食。最后一次喂食之后才判定本轮是否增加一个成功步骤。失败仍消耗已经吃掉的食物，并进入互动冷却。取消后保留尚未消费的携带物，不返还已经摄入的部分。

| 能力 | 玩家设置 | 实际行为 |
| --- | --- | --- |
| 服从 | 勾选训练，学成后可更换主人 | 首次学成自动指派训练者为主人；两个跟随开关仍默认关闭 |
| 释放攻击 | 学成，开启征召跟随，再征召主人 | 主人的“释放攻击 / 召回动物”开关扩大或恢复协同防御范围；犬实际接敌并造成身体伤害 |
| 救援 | 学成即可，不要求主人 | 寻找附近倒地居民，预留病人与床位，靠近后驮起同一人物，走到床旁再放入实际床位 |
| 搬运 | 学成即可，不要求主人 | 按独立间隔尝试搬运，将地面物资从较低优先级位置送到可接受的仓库或货架 |

开启后继训练会一起开启服从训练；取消服从训练会取消后继的继续训练意愿，已有成果仍保留。幼犬可学习服从和释放攻击；救援、搬运要求实际体型，拉布拉多需要长到成年才满足。

训练步骤与“已学会”分别保存。遗忘每次只减少一个仍有进度的末端技能一步，曾学会的能力直到降到零才失效。部分退化的前置能力仍可使用，但必须补满才能继续训练后继。没有把所有技能同时减一级，也没有在每次成功训练后重新开始遗忘计时。

## 跟随、战斗与救援

征召跟随与野外工作跟随独立设置。当前野外工作映射到采矿、伐木、收获、种植和狩猎等已有任务，室内制作不触发。犬使用自己的地面寻路图，不使用居民梯子；真实坡道、门、围栏、火焰和区域限制仍有效。跟随者走到主人附近并随主人移动重新规划，渲染层不代替移动逻辑。

释放攻击是主人的群体指令，只影响已学会对应能力并开启征召跟随的动物。普通近身防御仍可发生；释放后扩大以主人为中心的目标搜索范围，召回恢复普通范围，解除征召清空释放状态。本轮防御目标限已有袭击者，咬伤进入现有居民身体与护甲流程；相邻袭击者也能用真实近战伤害反击犬，伤口继续进入动物医疗系统。

本轮没有实现 Odyssey 的单目标 AttackTarget 技能，也未覆盖原版近战威胁的全部特殊关系、主人被敌人搬走的保卫分支、羁绊加成和完整动物战斗 AI。动物受伤后会沿用现有逃离、救助与休养机制；这里不是原版完整战术行为的逐项等价复现。

救援复用居民的真实身份和 `carriedBy` 关系，动物工作保存对应病人与床位。动物、医护不能同时预约同一病人或床。到床后只完成搬运，不瞬间治疗；医生仍需实际取药、靠近、护理与喂食。救援中断时病人留在动物当前实际位置；床、病情、动物能力或通路失效会释放预约。

## 物资、取消与存档

搬运使用同一份地面 `Stack` 和实体 `Cargo`，与居民共享来源份额、仓位容量和堆叠规则。衣物、武器、尸体、打包家具、未完成品和受精蛋继续保留各自身份及批次字段；正在由作者加工的未完成品不能被犬抢走。仓库筛选或容量变化时重新找目标；无法继续则取消任务，已经拿走的物资仍在犬身上，等待有空间时完整放下。

| 中断 | 保留与恢复 |
| --- | --- |
| 训练取消、饲养员被征召或改变分工 | 清理训练预约，保留未吃掉的食物和已有训练进度 |
| 来源被禁止、卖出、腐坏或份额不足 | 停止未完成的取物，物资只按真实变化记账 |
| 犬饥饿、受伤、被照料、主人改变或指令改变 | 停止不再成立的协作，保存携带物；救援解除双向携带关系 |
| 犬死亡且附近没有卸货空间 | 保留死亡动物与携带物，直到可完整落地后再转换为独立尸体 |
| 出售或放归 | 不允许带着货物或病人直接交易消失；放归需先安全卸货 |
| 携带易腐食物或受精蛋 | 使用携带者所在位置的温度继续腐败或孵化，实际消费、转换、生成与损毁参与账本 |
| 保存与读取 | 保存训练意愿、步骤、已学会状态、计时、主人、工作阶段、携带物和患者关系；重建实物预约 |

v59 为旧动物补充独立的未训练默认状态，旧居民默认没有释放动物指令。旧存档不会凭空获得犬、训练成果或协作任务；旧生产筛选不因新增物种而扩大。历史交易中的动物快照只读保存当时成果，不能当成另一只实时动物或再次占有其货物。

## 验证边界

本轮只使用原版安装文件的静态分析、无界面模拟、React SSR、CPU 渲染对象检查、类型检查及构建；没有运行原版、浏览器、预览或 GUI 交互。动画与模型测试核对真实数据绑定，不能代替实际画面与手感验收。发布流水线继续只安装、构建和部署，测试在本地执行。

专项检查覆盖训练前置与衰退、两次真实喂食及取消守恒、主人与跟随指令、真实救援和搬运、特殊物品身份、中断恢复、历史迁移与只读交易快照。完整结果、失败尝试与源码身份保存在[验证回执](evidence/animal-training-voxel-validation.json)，不以单次按钮状态或强行设置成功字段代替玩法验证。本地复核入口：`node scripts/research/verify-voxel-animal-training-validation.mjs --local`。

四个新测试文件分别检查模型与严格迁移、实际工作流程、携带物边界、SSR 和 CPU 渲染数据绑定。受控场景提供地形、物资与起始状态，核心操作经过公开命令与真实模拟 tick；用于隔离技能资格或资源预约的单元测试会直接构造状态，不作为从零训练的证明。

所有早期失败报告保留：交易夹具最初没有相邻交谈，战斗断言误读 `attackerId` 而非实际 `shooterId`；特殊货物夹具含不合法的耐久或尸体体型，孵化断言忽略出生当帧的自然成长。旧迁移测试也需要明确新增字段所属版本，交易供给断言随新增公母犬从四只调整为六只。实际修复包括反击伤口映射 `blunt` → `bruise`，以及将堆叠/携带常量移到独立模块以消除模块循环。修复后按完整测试文件重跑，不删除失败记录或拼接单项成功结果。

全量回归首轮为 **161 文件、2,144 项：2,140 通过，4 失败，无跳过**，失败均为旧结构断言：真实 v38 迁移与旧饮食政策的预期适配器应明确新增 `animalsReleased:false`，同时仍完整比较原居民字段；雏鸡现在拥有空的 `cargo/work` 槽，应断言两者为空且没有继承携带者的技能，而不是要求 `cargo` 字段不存在；新建生产政策的完整物种列表应含拉布拉多，旧档已有筛选仍保持原选择。这些修订不改变实际孵化或生产行为。

四个相关文件整文件复跑 **64/64 通过**，未放宽超时、删除断言或跳过测试。按所有文件的最新完整结果，最终 **161 文件、2,144 项通过**；其中新训练模型 19 项、实际工作 27 项、携带物 13 项、UI/CPU 渲染 16 项。类型检查与生产构建通过。长周期食物回归实际推进 97,025 tick（8.085 游戏日），收获 90 份谷物并逐 tick 核对账本。

真实历史兼容性验证使用已发布 v58 的做饭和布帽制作中间存档，分别运行精确历史引擎和 v59：从 tick 301422 推进至 302172，完成 **750 tick、756 次完整状态比较、5 次重载**。两个引擎都产出一份餐食和一顶布帽，10 份谷物、1 份木材和 20 份已继承的布料仅记账一次。每张工作台原本已有显式生产队列，全部队列、政策、随机数、生物状态、计时和旧任务都保留在比较中。

仅对版本号和逐字段断言未启用的训练/工作/携带默认状态、居民未释放动物状态、默认犬宰杀设置及零交易账本做归一化；不删旧生产设置来掩盖差异。历史来源核对 103 个文件，旧引擎构建哈希与已发布凭证一致。该续跑证明旧营地连续性，不代表已经完成一次自然新开局的养犬全流程验收。

原版独立静态证据核对 **55 个类型、116 个锚点、16 项限定检查、25 项 XML 投影**；17 个复用类型与此前研究一致。训练和战斗参数继续作为可调整的初值，不把通过机制测试等同于数值已平衡。
