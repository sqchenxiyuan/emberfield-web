# 动物环境生存：温控、避险、救助与恢复

本轮优先补齐经营机制：动物实际所在房间的温度，会影响疾病、行动与救助；火灾也进入已有动物伤口系统。数值集中保留为可调默认值，未做平衡性定稿。原版依据见 [153 静态机制](153-animal-environment-mechanisms.md)，下文描述独立 Web 实现与适配边界。

## 玩家能够做什么

1. 选中动物查看当地温度、该物种的舒适区与安全区，以及失温、中暑的当前严重度。当地温度来自动物脚下的房间，不能只看室外温度或地图生物群系。
2. 为圈养动物安排温控空间、开启可通行的门，并在适温处放置动物医疗睡眠点。五种动物的耐受范围不同；床所在位置也需要适合该患者恢复。
3. 可行动的患者可以自己走向合适病床；较严重且没有医疗任务接管的殖民地动物，会沿实际地面通路寻找适温位置。墙、关闭的围栏门、占用和允许区域仍然有效，动物自己不能爬梯。
4. 倒地动物需要医护或饲养员实际靠近、抱起并搬到合适睡眠点。原床变得不适合时，可以安排转移到另一张适温床；抱起和放下不会清除病情。
5. 温度疾病依赖环境逐步恢复，草药不能治疗纯失温或中暑。烧伤仍属于普通伤口，可以护理；两类状态可以同时存在。
6. 野生动物遇到不安全温度，会实际走向地图边界，抵达后离开。它在途中仍是同一只动物，受伤、倒地或断路都会影响离图。

这使房间、温控、通路、医疗睡眠点和饲养分工共同影响动物存活，避免把环境生存做成单独的血量扣减。

## 机制衔接

| 情况 | 当前行为 |
|---|---|
| 超出物种安全温区 | 按模拟时钟累积对应温度疾病；低温和高温严重度分开保存 |
| 回到安全缓冲区 | 病情可以停止加重，但不一定开始恢复；失温需高于舒适下限，中暑需低于舒适上限 |
| 病情加重 | 与伤口状态合并影响疼痛、移动和倒地；致命时进入现有单次死亡及实体尸体流程 |
| 无可用医疗睡眠点 | 可行动动物仍能觅食；较严重病患尝试环境避险，不会因反复找床阻断普通决策 |
| 已到适温位置 | 普通觅食、求偶、产蛋和游荡不主动选择妨碍恢复的目的地；产蛋可以放弃危险蛋箱，在安全处落地 |
| 避险途中遭攻击 | 清理环境路线，交给威胁逃跑；当前脚下有火时先逃离火格，任务阶段与目标保持一致 |
| 真实地面火焰接触 | 产生持久烧伤；能走的动物寻找可达非火格，倒地者仍需灭火或救助 |
| 转运中被征召等中断 | 保留病情，动物留在搬运者位置，不复制、不传送、不清除伤口 |
| 购买或出售病患 | 保留同一个体和温度疾病；每笔交易保存独立历史快照，不随着之后恢复而改写历史 |

普通目标只筛选目的地，尚未给整条路径增加温度代价。显式允许区域、牵引和商队跟随保留各自的任务规则；它们不等于自动建立恒温饲养区。玩家仍需要保证通路和生活区域适宜。

## 数据与调参边界

- `animalEnvironment.ts` 集中物种温区、采样、病情阶段和恢复参数；`animalEnvironmentWorld.ts` 集中接触烧伤、避险搜索上限与重试节奏。
- 存档版本为 **v55**。每只动物及交易历史快照新增独立的 `environment: { hypothermia, heatstroke }`。旧档只补零值，不补算过去的冷热伤害。
- 新档校验疾病字段、有限值、严重度、存活状态和避险阶段/路径；伪装旧版本混入新字段会被拒绝。
- 疾病状态不占物品堆，不消耗额外随机序列。安全且无病的动物不修改这两个零值。
- Web 采用现有时间比例映射原版温度采样。寻找避险点使用有上限的实际动物邻接搜索；不是原版 Region 搜索复刻。

## 验证与证据

本轮只运行静态分析、无界面模拟、React SSR/CPU 几何检查及构建。没有运行或交互操作原版、浏览器、预览或 GUI，没有 GPU 画面或人工试玩验收。

专项测试包括：实际房间温度与物种差异、纯温病拒绝无效用药、真实救助及在途读档、适温床转移、逐步恢复、关闭门与墙阻断、死亡单次结算、火格接触烧伤及逃离、无床觅食、到达避难点后保持适温目标、受击中断、真实走到边界离图，以及实际交易保留病情。夹具对地形、病情或温度的注入均为受控测试，不称为自然新营地环境经营验收。

真实旧档验证使用已发布 v54 的既有烹饪与布帽制作中间存档，由同一份存档分别驱动精确 Git 构建的旧版本和当前版本。仅允许版本号与逐只确认的零值环境字段差异，逐帧比较完整存档，不通过改写病情、路线或旧字段制造一致。

本地回归覆盖 **147 个测试文件、1,918 项检查**。首次全量有两项耗时超限；随后在不改变超时限制和断言的情况下，单 worker 完整重跑它们所在的两份文件，20/20 通过。按每个文件最新完整结果，全部通过；所有首次失败报告仍被收录，不拼接不同运行中的单个成功断言。约 9.7 万帧的实际种植收获过程也逐帧审计物资。

真实 v54→v55 续跑已通过 **750 帧、5 次读档、756 次完整存档对照**，从 tick 301422 推进到 302172，继续完成一份饭和一顶布帽；原有 10 粮、1 木及未完成品中的 20 布没有重复计账或丢失。最终本地检查及构建资产哈希见 [验证回执](evidence/animal-environment-voxel-validation.json)。

该命令读取本机保留的证据、测试报告、旧档与构建产物并核对哈希，不自动重跑游戏或测试。真实旧档续跑脚本依赖根仓库历史和本机保留检查点，新克隆需恢复这些输入。GitHub Pages 流水线仅安装依赖、构建、部署；测试在本地运行。

## 尚未实现

原版的附着身体火焰、动物自行灭火、同伴扑灭附着火、冻伤、极热空气烧伤、完整器官和随机倒地死亡仍未实现。当前地面火格接触不是完整的原版点燃系统。野生动物离图使用当前实际危险温度，尚未复刻原版季节适居判断和户外温度分支；温度路径代价、自然新营地长周期经营及浏览器操作体验仍待验证。
