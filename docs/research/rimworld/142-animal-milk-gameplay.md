# v49：单峰驼产奶与食物链

这一轮把畜牧接入可重复的物资生产：荒漠野生单峰驼 → 实际取粮与驯服 → 圈养或照料 → 成年雌性积奶 → 饲养员到场挤奶 → 奶作为普通实物进入仓储、食用、烹饪和贸易。机制优先，产量、工时、出产节奏和经济收益后续统一调整。原版证据另见[141 静态机制](141-animal-milk-mechanisms.md)。

## 玩家操作与生物状态

新荒漠营地的野生动物包含单峰驼，可以选择查看、标记驯服、牵入圈地、设置物种/性别接纳和自动宰杀配额。单峰驼和鹿都是圈养动物，普通行走不能穿过围栏；兔继续使用活动范围。各物种仍有独立的营养需求和驯服门槛，奶不属于这些草食动物的直接饲料。

殖民地成年雌性单峰驼自动积奶，不要求怀孕或生产经历。饥饿按正常、饥饿、急饿、挨饿依次使用 1、0.5、0.25、0 倍速度；满后停止积累。失去产奶资格仅暂停增长，不凭空清除已有奶量。新生幼崽从零开始。野生动物不积奶，鹿和兔也不会产奶。

开启「饲养」分工后，满奶且符合互动冷却、通路、区域和独占预约条件的动物会获得挤奶任务。挤奶不套用驯服的最低技能门槛，但动物技能、操作能力和视力影响速度与成功率。界面显示真实奶量、当前饲养员和实际工作阶段；单峰驼有独立的程序几何形体，挤奶动作由真实互动任务驱动。

## 现场工作与物资守恒

饲养员先走到动物旁边再劳动。动物生物积累和工人工作进度是两份独立状态：征召、关闭分工、通路或区域改变可中断任务，奶仍留在动物体内，重新派工从零工作开始；原任务保存后载入则保留路径和小数进度。手动宰杀、放归以及自动宰杀优先于挤奶，同一只动物不能同时被两人挤奶或牵引。

完成后按工人能力作一次成功判定。失败丢失这一整批生物产物，奶量归零，但不会在实物账本中虚构一堆奶及其消耗；成功在工人附近放下普通奶堆，登记一次生产，奶量归零。成功率达到 100% 后不额外增加产量。

Web 对极端拥堵作了明确适配：先检查整批产物的可用落地空间，空间不足时保持满奶和已完成工作，等待期间不继续获得经验或重复结算。成功落物与生产账本一起提交。原版路径没有检查放置返回值，不能把这一保护称为原版等价行为。

奶遵守普通堆叠、拆分、合并、禁止/允许、货架、搬运预约、腐败、露天耐久和贸易规则。生饮按营养计算实际份数，不增加普通生食负面记忆，仍可能食物中毒。简餐可以混用谷物、肉和奶，已搬入材料保留来源与腐败进度，账单过滤控制实际取料。大宗商人接受奶，不代表本轮新增了商队售奶库存。

## 存档与暂定参数

存档升级 **v49**，增加动物 `milkFullness`、挤奶任务、奶的六份资源账本、单峰驼自动宰杀策略及圈地接纳开关。v1–48 动物补零奶量，资源账本补零，单峰驼配额全部不限。旧圈地默认不接纳新物种，旧仓库及账单的显式筛选保持原选择，玩家可自行启用奶和单峰驼。旧版本标签夹带新版字段会在历史迁移前被拒绝。

当前奶采用 2 游戏日/18 份、400 工作量、每份 0.05 营养、14 天常温腐败、75 堆叠。Web 一天仍是 12,000 模拟 tick，不能把原版 60,000 tick 的时间参数直接当作 Web 实秒。技能速度和成功率表达式参考静态证据；全局工作速度、完整动物伤病、特殊基因和 DLC 修正尚未接入。

荒漠每三只初始/补充野生动物中的一个位置使用单峰驼，是本轮可玩性分布，**不是**把原版 Desert 的 0.7 相对 commonality 当成 70% 概率。单峰驼肉量、生命、移动、成长、妊娠沿用集中配置的 Web 简化规则，没有声称完成原版平衡或长期牧场收益校准。

本地测试区分显式构造的边界夹具、确切历史代码生成的迁移存档，以及仅通过公开玩家命令推进的新荒漠经营流程。测试覆盖积奶资格和饥饿、工作速度与整批失败、实际步行、互斥预约、中断/恢复、小数进度存读、拥堵不重复经验或产物、食物加工和严格存档验证。界面采用服务端渲染和无需 GPU 的几何检查；没有浏览器视觉验收。
