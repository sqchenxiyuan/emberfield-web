# v50：剪毛与材料决定的衣物

这一轮把畜牧接入衣物生产：温带羊驼 → 驯服与圈养 → 成年公母长毛 → 饲养员到场剪毛 → 羊驼毛实物 → 裁缝选料 → 未完成品 → 穿衣御寒。优先搭通资源来源、实际劳动和生活反馈，产量、周期、工时及经济收益暂不做整体平衡。原版静态依据见[143 剪毛与材料机制](143-animal-wool-mechanisms.md)。

## 羊驼与剪毛

新温带地图的部分野生动物为羊驼，可查看、驯服、牵引进圈地，并设置物种接纳和自动宰杀配额。Web 每三个温带动物生成位置使用一个羊驼位置；这是初始玩法分布，不是把原版相对权重 0.5 当作 50% 生成概率。单峰驼继续产奶，不能剪出羊毛。

殖民地成年羊驼公母均自动长毛，没有怀孕条件。饥饿减慢或暂停生长；幼崽、野生、死亡等不满足条件时不增长，已有进度保留。满毛后等待开启「饲养」分工的殖民者靠近劳动。驯服最低技能不作为剪毛最低门槛；动物技能和身体能力影响劳动速度及整批成功率。

任务使用真实路径、允许区域和独占预约，不能同时牵引、剪毛或宰杀同一动物。取消和征召中断保留动物毛量，新任务重新劳动；保存原任务后载入则保留小数工作进度。宰杀、放归和饥饿喂食优先于剪毛。成功在工人附近放置普通羊毛堆；失败清除本轮毛量，没有凭空产生实物或消耗账目。成功率超过 100% 不提高数量。

与 v49 挤奶相同，Web 在结果判定前检查整批落地空间。空间不足时保持满毛与已完成工作，等待期间不重复经验、随机判定或生产。这项拥堵保护是 Web 适配，不能声称与原版忽略放置返回值的路径完全等价。

## 羊毛、裁缝和穿戴

羊驼毛是独立的 `alpacaWool` 资源，支持禁止/允许、搬运、堆叠、地面及货架储存、露天耐久、火灾和大宗贸易。它不腐败、不可食用；单堆上限 100，单次搬运上限仍为 75。商人接受羊毛不等于本轮新增了商队售毛库存。

裁缝账单可勾选布料和羊驼毛。每件衣服使用一种纺织材料，同种材料可来自多个堆，但不能把不足量的布和毛混合凑足。选料遵守原料半径、通路、区域、禁止状态及其他工作预约；两个都不允许就缺料等待。开始领取后的批次保留材料选择，改变账单筛选影响后续批次。

实际送达的材料进入独立未完成品，身份、耐久、数量、作者和加工进度随存读保留；继续沿用原作者续作、暂停/删除账单保留未完成品、单独取消退回实际原料等规则。完成时按实际材料消费，成衣 `material` 保留 `alpacaWool`，不变成布制衣物。

材料影响实际隔冷、隔热、热伤防护、燃烧性和价值；品质在材料贡献后应用。羊毛衣物更耐寒，但不因为原料耐久高于布而凭空增加成衣耐久，工作量也不随原料耐久变化。衣物只在穿上后影响人的舒适温度，携带不产生御寒效果。成衣价格计算真实材料投入与劳动，仍受品质和破损影响。

本轮同时按所查 Core 定义修正纺织未完成品为不可燃；原料羊毛与羊毛成衣有不同燃烧值，不能互相套用。其他未完成品和钢制护甲仍保留既有 Web 火灾适配，不代表完整材质系统已经完成。

## 参数与存档边界

主要默认值集中在 `animalWool.ts`、`husbandry.ts`、`wildlife.ts`、`apparel.ts` 及资源规则模块。当前参考原版羊驼 10 游戏日/45 毛、1700 工作量，Web 一日仍是 12000 tick；成长、妊娠、生命、肉量、移动和人口分布沿用明确的原型配置。没有据此宣称完整复刻原版时间或牧场经济。

存档升级 **v50**：动物 `woolGrowth`、剪毛工作与事件、羊毛六份账本、羊驼圈地开关及自动宰杀策略、衣物材料和账单 `allowedTextiles`。旧动物和账本补零，旧圈地不自动接纳羊驼，旧配额不限；旧仓储、食材和尸体筛选不扩容。已有账单、冻结工作和未完成品补为只允许布料，旧衣物不改材质。新账单默认允许布和羊毛。旧裁缝台若只保存隐式配方，会迁移成具有原 legacy 身份的显式账单，材料仍限布料，已有作业补上对应账单引用。旧版本夹带新字段会在历史迁移前被拒绝。

## 本地验证与未验证内容

原版静态复核通过 **34 个派生类型、60 个锚点、6 项有界检查、37 项 XML 投影**。这属于安装文件及派生代码证据，本轮没有运行原版。

新机制使用明确构造的地形、成年动物和初始库存夹具隔离边界，验证之后的实际劳动、资源守恒、工作中断和存读。剪毛到穿衣的集成用例实际产出 45 羊毛，工人建裁缝台并搬料，将 20 羊毛封装成未完成帽子；存读后即使当前账单改成布料，仍产出原羊毛帽，留下 25 毛，穿戴后改变舒适温度。另测单材料不足、空筛选等待、成功/失败、拥堵不重复经验或产出、非法存档，以及材料属性、价格与容器行为。**这些是控制夹具，不是从新营地自然经营十天的验收。**

真实 v49 迁移基线来自根提交 `2b50bcae1bbcb9ffb0890630de609c74da460547`、发布子树 `91aae567053c15635b7477745f165cbffa7ad686`。89 个历史依赖与已存证的自然产奶流程一致，取真实中途挤奶检查点继续到 tick 125365、进度 125。迁移后与旧模型对照 **335 tick**，三次重载，继续产生恰好 18 奶、0 羊毛；六件布制衣物及旧过滤选择保留。产奶基线来源见[历史基线](evidence/animal-wool-v49-provenance.json)。另以真实 v16 衣物经营存档交给冻结 v49 代码，通过公开命令和 131 tick 形成布帽未完成品（tick 301264，进度 20）。迁移后与旧模型逐 tick 对照 873 tick，两次重载，实际完成恰好一件布料帽，隐式账单身份、原材料和作者保留；原 v16 文件与挤奶基线均未改写。
