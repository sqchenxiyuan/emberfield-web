# 65 · 体素财富、叙事日历与袭击预算验收

日期：2026-11-03。存档 v20。本章区分普通经营、浏览器实际控件、旧存档兼容和受控规则测试。正式经营从新营地起步，在保留一次真实选址失败后正常读档继续；同一冻结游戏 bundle 完成真实多人袭击、受伤、草药护理及同一伤者康复。Worker 与 main 的完整浏览器验收均已完成。

## 验收边界

本轮新增 Cassandra 日历、六档难度、物品/建筑/人物财富、健康人口点、适应反馈和按预算组队。没有提供 Randy、Phoebe、交易系统或完整原版派系、袭击策略与装备池。页面中的财富是估值，当前威胁点是营地条件的估算，下一次机会仍须满足入场条件。

项目每游戏日 12000 tick；每 200 tick 检查事件日历。开启或关闭袭击不会把日历重置成“三天后必来”，关闭期间错过的机会不会在再次开启时补发。旧 v19 已预约的一次袭击单独保留，不重新抽签。

财富核验分别看物资数量、实体归属和估值变化。搬运、穿戴、取用与交料不能重复计价；已交付的易腐材料及其年龄记录是同一批材料，不应累加两次。生产完成、饮食、腐坏、装备损耗、拆除和死亡可能实际改变估值，因此不把“总财富永不变化”当作守恒条件。已装入并消费的燃料使用既有浮点记录，不额外当作库存物品加价。

新墙体和楼板保存不同结构身份。旧 v19 没有足够信息恢复原始身份，使用明确的兼容估价，并在界面显示旧结构格数。不会仅靠现有几何猜成原始建造行为。

## 普通经营验收方法

脚本：`scripts/voxel-storyteller-campaign-verify.mjs`。从种子 73129 的新营地开始，只用普通命令、step、save/load 改变状态；只读地形和寻路查询用于选择施工地点。没有授予资源、财富、技能、科研、装备、伤势、事件或时钟。

准备过程包括真实粮食生产、有限采矿伐木、研究、枪械和护甲制作、穿戴、药根收获、床位及结构扩建。独立按原版资源单价检查地面、携带与工地已交材料；同时核对装备唯一归属、库存数量和既有生产/消费/损毁账本。敌人带装备入场或携装备离图单独作为外部转移记录。

完成准备后，使用普通难度命令明确选择 extreme，并只开启一次袭击；不会逐波关闭重开以寻找有利日程。真实同一保存点的六难度对照只比较预算和状态，不能当成六次独立经营样本。时间正常推进至既有事件机会，验证实际预算、实际生成成员、已花点数和余额；至少观察一场多人袭击。

真实受伤、倒地或死亡必须按结果保留。普通护理、进食与休养构成恢复证据；如没有观察到适应损失，不能把健康下降或静态公式当成实际扣值。不同照护分支须声明同源保存点，不能作为概率统计。任何未覆盖的必要环节必须显示为未覆盖或失败。

相同真实保存点执行相同普通操作的重载对照，比较事件日历、机会时间、组队预算/人员和适应状态。主线先正常推进至机会前 120 tick，保存后分别重载两次并推进这 120 tick，比较真实入场结果；没有重复模拟此前整个和平等待期。与实际时间无关的独立对照不计入主线经营时长。

## 浏览器验收方法

脚本：`scripts/voxel-storyteller-browser-verify.mjs`。在本地生产预览的 Worker 与 main 两种模式下，实际操作难度下拉框、允许袭击复选框、菜单、文件选择器和导出按钮。`snapshot`、投影及存档导出 API 仅作只读观察；没有通过内部 command 或改写场景完成步骤。

覆盖八份真实 v19 兼容、实际扩张财富、六档难度、和平模式、关闭/再次开启不重置日历、跨过关闭时的真实机会后不补发、正常浏览器时间产生敌人、多人名单和预算明细、伤病人口贡献、实际适应损失（若发生）、真实康复、可见导出/导入和 900×700 控件可达性。页面加载的 JS/CSS 字节与本地 dist 对照，同时保留浏览器错误和截图哈希。
