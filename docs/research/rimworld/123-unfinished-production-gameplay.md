# 未完成品：加工中断、搬运和继续制作

更新：2026-11-04。继续按“玩法与机制先完整、数值后调”的顺序推进。原版证据见[122 未完成物品机制](122-unfinished-production-mechanisms.md)。本章描述 Web v41。

## 玩家操作

现有五类裁缝衣物、六种武器和两种护甲共13条配方，在原料运齐并开始加工时产生一件独立的未完成品。地图上可以选中它，查看配方、作者、加工进度、内含材料及绑定账单。人物携带时也能从人物面板查看。

暂停账单保留物品与进度；删除账单仅解除绑定。未完成品可以像其他物资一样运进仓库或货架，随后由原作者取回。同配方的新账单可让原作者在另一座兼容工作台继续制作，不必再次寻找原材料。新账单的原料搜索半径不限制已经封装好的未完成品，但仍然需要可达的真实通路。

加工时可以将未完成品放在工作位置或同层相邻的可用格，第一件成品占格时仍能开始下一件。空间全满则保留材料等待；不会隔墙或跨层加工。完成和取消会把未完成品自身的堆位计入可用空间，多种材料退回需要的全部位置都能容纳才会一次性执行。

作者与账单指定工人是两个不同条件。改成另一位工人不会把物品的作者改掉；重新派工时同时检查作者、账单分工及配方技能门槛。当前执行者在编辑分工时继续工作，下次重新分配才检查新规则。作者死亡或离开后，物品仍保留，可手动取消回收材料。

“禁止搬运与续作”会释放当前工作/搬运预定，保留物品。只有单独点击“取消加工”才拆开物品退料；附近空间不够时整件保持原状，不做一半退款。取消不算完成，不扣账单次数。

## 材料和保存

未完成品是单件 `Cargo`，有独立内部身份，仅由地面或人物随身容器持有。生产任务只引用这个身份，不再额外保存一份材料。封装、搬运、暂停和删除账单不计原料消耗；成功放置成品后才一起移除未完成品、消耗内含原料和扣减完成账单次数。损毁则记录包装实体及内含材料的损失。

资源总量包含封存在未完成品中的材料；可取用的散料和仓储筛选仍以真实外层物品为准。未完成品不参加贸易，Web 暂按零财富处理；本轮没有闭合原版市场价值公式，不把这个初值称为原版规则。成品品质在工量完成时锁定，随物品保存；重复取回或读档不会重新抽取已锁结果。

保存格式升到 **v41**。验证独立身份、配方成本、作者、进度、账单和任务引用，拒绝重复实体、嵌套材料或不一致副本。已有 v40 在制任务保留实物与进度，在下次实际加工时封装；v40 没有永久作者字段，已失去 owner 的旧任务无法恢复历史作者，因此以升级后首次接续者为作者，不能宣称追溯出了原作者。

## 明确的适配与后续范围

- 原版取消未完成品按75%随机取整退料；Web 暂用全额退回真实材料，先保证可逆的玩法闭环，后续统一平衡。
- Web 继续使用20 TPS和三维寻路，未完成品随原实际批次保留工作总量；跨不同效率的工作台不会重算已经完成的比例。
- 未完成品基础耐久暂取50，完整原版材质倍率后续再调。现有原料均非易腐材料，没有引入食物容器或递归容器。
- 烹饪、屠宰、切石继续使用现有非未完成品流程；本轮不声称已对齐它们全部原版中断重置规则。
- 成品指定仓库、更多材料替代、作者失去工作能力时原版细分解绑条件和完整配方库仍待扩展。

## 验证入口

- `tests/voxel-unfinished-production-model.test.ts`：成本、工量、身份、容器、保存与禁售边界。
- `tests/voxel-unfinished-production-integration.test.ts`：真实调度、首次封装、暂停/删除、搬运、跨工作台续作、作者限制、禁止、取消和损毁。受控地形、物资与技能仅用于边界测试，不冒充普通经营。
- `scripts/voxel-unfinished-production-campaign-verify.mjs`：从保留原始字节与SHA-256的真实v40加工存档连续推进，只用公开命令、模拟tick和存读档，逐tick审计材料守恒。
- `scripts/voxel-unfinished-production-browser-verify.mjs`：浏览器Worker/主线程的可见控件、选物、搬运模型、保存导出及导入。
