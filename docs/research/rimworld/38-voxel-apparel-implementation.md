# 体素棉花、裁缝与衣物实现

本章记录独立 Web 体素入口的实现；原版静态规则见 [36 章](36-apparel-tailoring-mechanisms.md)，原版实际操作见 [37 章](37-native-apparel-runtime.md)。两种证据不能互相替代。世界仍为 64×64×16，多层寻路与实物搬运沿用现有系统。

## 从种植到穿衣

在有阳光、肥力足够的土地上选择「种植区 → 棉花」。棉花按 8 个满速生长日累计，成熟收获每株 10 布料；受昼夜、光照、气温和土壤影响，实际日历等待更长。采收直接产布，不增加纺纱中间步骤。布料不能吃，不进入谷物或烹饪配方，也不按食品腐坏。

建一张 3×1 手工裁缝台需 75 木材，R 旋转。台前标记为操作位，请保留两格净空和通路，尤其不要把工作台放在梯口唯一出口上。点击台子，为不同衣物分别设置目标数量，启用人物「加工」分工。工人先实际送布，再站在操作位缝制，成品须有合法落点。

| 衣物 | 布料 | 普通布制隔冷 / 隔热 | 单件穿或脱时间 | 本项目工作量 |
|---|---:|---:|---:|---:|
| 无边帽 | 20 | 9 / 0°C | 0.8 秒 | 800 tick |
| 派克大衣 | 80 | 36 / 0°C | 3 秒 | 5334 tick |
| 防尘长外套 | 80 | 10.8 / 15.3°C | 3 秒 | 6667 tick |
| T 恤 | 40 | 3.96 / 1.8°C | 1.5 秒 | 1067 tick |
| 长裤 | 40 | 3.6 / 1.44°C | 2 秒 | 1067 tick |

本项目 20 TPS，表中生产工作量已经包含手工台 0.5 速度，并按原版 60 TPS 换算；按健康普通工速计算。原版实机室外木手工台显示 40% 工作速度；本项目当前只应用台本体 50%，未叠加室外 0.8 因子，不能把本表用时称为对该室外实验的逐秒复刻。工作台建造以木材工作系数 0.7 计算为 467 tick。日历磨损则按原版 60000 tick/日到本项目 12000 tick/日转换，这两个时间尺度不可混用。

目标数量统计全营地该种衣物的实物，包含地面、背包和穿戴；排入的生产任务也避免多个台重复补货。提高或降低目标保留当前批次；暂停该配方会中断并返还已送材料，空间不够时保留待退状态。新开局已有 3 件 T 恤和 3 条长裤，所以这两种目标设为 1 不会额外生产。

选择落地衣物后指定穿戴者，点击「前往穿上」。人物走到衣物位置取用，再花时间穿衣；同一身体部位上的同层衣物互斥。派克大衣与长外套替换，帽子、T 恤、裤子可以共穿。换装耗时包括新衣和冲突旧衣的穿脱时间，旧衣须真实放回地图。人物衣着栏可逐件脱下。

## 保温、磨损与保存

每件衣物具有唯一 ID、类型、布材质、品质、耐久和穿着计时；地面、背包、穿戴列表只能有一个归属。衣物每格、每次携带 1 件，不合堆；布料每堆 75。仓储新增「布料与衣物」过滤预设。满地时生产和换装等待，原料、成品和旧衣均不能凭空丢失。

隔冷降低舒适与安全低温阈值，隔热提高高温阈值，直接进入已有失温和中暑严重度更新。品质倍率为 0.8 / 0.9 / 1 / 1.1 / 1.2 / 1.5 / 1.8；当前制作只产普通品质，不假造技能品质分布。所选布衣耐久不影响隔热强度，只有销毁、脱下或替换后才失去贡献。不同品质的这些布衣耐久上限相同。

每名人物的穿着磨损调度器每游戏日检查一次，当时穿着的每件衣物有 40% 机会损失 1 HP。项目用种子、衣物 ID 和人物磨损天数确定性抽样，便于存读档一致；不是原版 RNG 序列，也不是每件独立累计一天才磨损。`wearTicks` 只记录实际穿着时间。磨损至 0 时销毁，记入 `stats.destroyed.apparel`；资源守恒口径为当前实物 + 消耗 + 腐坏 + 损毁 = 初始实物 + 生产。

v11 保存衣物身份、穿戴、在途穿脱、配方、工作进度与磨损计时。兼容 v1～v10，旧营地不补发免费衣服；新世界的三名人物各自带普通布 T 恤和长裤，是固定开局配置。本轮迁移用真正修改前导出的 v10 文件验收，未把新存档改版本号冒充旧档。

## 验证与边界

验证入口：

```sh
npm test
npm run test:voxel:apparel
npm run build
# 保持预览服务运行，并按需要设置 VOXEL_TEST_URL
npm run test:voxel:apparel:browser
npm run research:check
```

正常经营脚本从新地图开始种稻、种棉、伐木、建灶、建梯与楼上裁缝台，不注入材料、生长、人物需求或时钟。浏览器脚本通过真实按钮、画布和文件选择器操作；调试接口仅用于读取状态、投影坐标和导出存档。这些是功能验收，不是只看屏幕的 Agent 评测。

最终结果及对应源码、构建、脚本、截图哈希由 `evidence/voxel-apparel-validation.json` 冻结记录，原始输出在忽略目录 `test-results/`。历史 35 章记录仍对应生存版本，不能拿其旧构建哈希指代本轮发布。

正式构建在 Worker 和主线程两条路径各通过 14 项浏览器检查，包含棉花选择、衣物检查、裁缝配方与暂停、实际穿脱替换、制作/换装中途读档、手动保存恢复及 900×700 界面。世界生成、林业和救援的浏览器回归均通过；同一页面完成 6 次保存/新世界/恢复，渲染几何数 27、纹理数 4 保持稳定。这是有界生命周期检查，不代表长时间泄漏或任意地图规模已验证。

截图：[棉花](evidence/voxel/apparel-cotton.jpg)、[裁缝订单](evidence/voxel/apparel-tailor.jpg)、[穿上外套](evidence/voxel/apparel-parka.jpg)、[小窗口衣着](evidence/voxel/apparel-compact.jpg)。完整冻结记录见 [voxel-apparel-validation.json](evidence/voxel-apparel-validation.json)。

全量单元测试 351/351 通过；11 组既有模拟经营回归通过。正常经营完成 25 项检查，运行至 tick 300025（25.002 游戏日）。64 格棉花共采得 640 布料，五款成衣消耗 260 布料，最终 11 件衣物包含初始 6 件；同期做出 105 餐简餐，最低饱食 12.71，没有倒地或死亡。实际穿过的基础衣物可见耐久下降，全部物资与身份守恒。

独立冷热对照共 12 项检查：每种气候生成两个同种子世界，一组保留初始 T 恤和长裤，一组通过正常命令脱衣，至 tick 70 才完全裸身。逐 tick 核对同位置、同温度和需求，tick 1800 保存并原样恢复，运行至 tick 3600。冷环境裸身失温 0.2235、热环境裸身中暑 0.07125，均造成能力下降；对应穿衣组的该项严重度为 0。此对照只验证基础衫裤，不冒称已在相同气候下实测派克大衣或长外套。

当前明确简化：仅布材质和五款衣物；固定普通制作品质；研究预解锁；没有完整技能、制作灵感、室外惩罚、房间角色和照明的工速修正、露天耐久、自动换装政策、污损、死人衣物心情、护甲、缺失身体部位和完整衣物数据库。棉花采收没有原版失败随机及受损产量因子。渲染用独立程序几何表现白色棉铃、布卷、衣物、缝纫和换装动作，没有复制原版贴图。帽子和外套随实物穿戴显示，品质和耐久尚无专用材质外观。
