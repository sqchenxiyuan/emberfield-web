# 河流、水域与架桥

更新：2026-11-04。v43 将世界选址、营地地形、渡河施工、物流和存档接起来，仍以玩法和机制为先。成本、河宽、出现频率与劳动节奏使用集中可调的初步参数。原版事实与适配范围见 [126 机制研究](126-river-bridge-mechanisms.md) 和 [128 原版实机](128-native-river-bridge-runtime.md)。

## 玩家操作

世界地图显示相邻地区之间的河流，地区详情与候选比较显示浅溪或河流；局部预览显示实际水道。新选址使用地区生成 v2、WorldSite v3 和局部生成器 4。自定义营地可选择无河流、浅溪或河流。旧地区身份仍解析到原来的配置与生成器。

浅水可以涉水，但会增加移动时间；人物和动物寻路使用同一水域通行条件，实际移动也计算涉水时间。深水不可步行，也不可架普通木桥。大河保留天然浅水渡口，玩家可以选择涉水或用材料改善路线。

在建筑工具中选“木桥”，沿浅水拖出连续规划。工人携带实际木材、到场施工，完成后才形成桥面；暂停、征召、取消与缺料使用既有任务机制。取消规划保留或退回实物，不清除水。原版浅水允许划仓储和放散货，Web 同样允许实际搬运入库；仓储标记不会把水变成干地。

木桥保留下面的水，只提供轻型地基。木墙、木门、床、桌椅、货架、电暖器和沙袋等可使用，石墙、切石台、裁缝台、科研台和多数机器不能直接放上去。设施仍需满足原有尺寸、净空与交互位置条件。普通楼板不能直接覆盖水域来绕过桥梁规则。

拆除桥后恢复同一处浅水；承载设施时需先拆走设施。桥烧毁会毁坏失去支撑的设施及直接承载的木墙，没有拆除退料。水体与河床保留。正常站在浅水桥上的人物可留在原位置涉水，其他失去支撑的对象仍走既有坠落与物资安置流程。

## 三维地形与保存

水使用独立 `Uint8Array` 保存：浅水占一个体素，深水占连续两个体素，下方均为实体河床。水面、河床、桥面有不同身份。桥由木结构块与独立桥标记表示，桥下的水不会被删除。水体内部不能作为站立位置，剖切水体也不创造可通行地板。桥上可以积雪，水体内部不能积雪。

新世界的排水网络按相邻格连接和上游降水累积生成；局部地图接收地区的入水、出水方向，多条支流在实际营地连通。河岸逐格降坡，出生区和开局物资保持干燥。局部地图海拔独立，这不代表世界各营地已能无缝拼接或旅行。

存档格式升级为 **v43**。水和桥使用与地形相同的 RLE 格式；分块只传递已探索水域。载入验证水柱、桥面、结构身份、轻型承载和积雪位置，不通过重新生成来恢复水。历史存档补全空水层和空桥层，保留原有地形、修改、生产与地区身份，不在旧营地自动开河。

## 原版边界与待扩展内容

- 原版 1.7 桥属于独立 foundation 层；Web 用木结构体素加桥标记实现相同的底水保留关系，并扩展到多层空间。
- Web 的三维噪声地形、相邻排水网络、河床体素、缓岸和天然渡口属于独立生成设计，不宣称复制原版的世界河流算法。
- Web 的 deep 表示真正不可通行的深水，不把原版可通行的齐胸流水误标成不可通行水域。
- 目前没有流体流动、压力、冲刷、地下水、冻结、游泳、溺水、船只、水力发电或自动填河。为避免制造悬空水，水域及直接河床暂不能开挖梯井或采矿。
- 未实现 Odyssey 的重型桥梁；普通木桥仍受浅水与轻型地基限制。三维建筑还没有完整的梁柱荷载与连锁坍塌计算。
- 本轮不追求原版每次施工失败概率、成本和速度的精确拟合。原版实机发生的施工失误属于观察结果，不据此声称 Web 已有同样的失败系统。

## 验证

`tests/voxel-rivers-generation.test.ts` 验证历史生成器 2/3 的固定哈希、三生态四种起伏的河床与水柱、四边汇流、无环世界河网、缓存隔离和版本身份。`tests/voxel-water-bridge-integration.test.ts` 验证实体施工、实际通行成本、存读、取消、拆除与火毁。`tests/voxel-water-bridge-save.test.ts` 验证真实历史档迁移及严格状态约束。

`scripts/voxel-river-campaign-verify.mjs` 从真实生成的新浅溪营地开始，通过公开命令连续完成三格桥、进行中读档、另一名居民走到桥上、拆桥、浅水仓储和实际搬运。每步核对全部资源账本，不写入物资、地形、技能、人物位置或计时器。报告保存在 `test-results/voxel-river-campaign/report.json`。

浏览器脚本 `scripts/voxel-river-browser-verify.mjs` 使用页面普通控件与只读检查，在 Worker 和主线程两种模式验证世界地图、生成预览、深水拒绝、拖桥施工、导入导出和拆桥。两种模式各 **7 项检查通过、0 浏览器错误**，保留 1440px 与 980px 截图，并核对实际下载的构建资源。检查中修复了水面低于当前工作层时的选择高度、桥板缝隙的射线命中；最初失败报告一并保留。最终 `npm run build` 成功，资源哈希与完整浏览器检查所用版本相同。

独立经营脚本 **10 项检查通过**，保留 5 份检查点：实际交付材料并施工、工地读档、三格桥完工、另一名居民走到桥上、拆桥、浅水入库与资源守恒。长回归连续推进 **97,025 tick（8.085 游戏日）**，取得 90 份实际谷物，再验证烹饪、途中存读与进食；长模拟及环境边界共 20 项通过，没有跳过生长或直接注入成熟作物。

本次全套本地回归覆盖 **114 个文件、1,517 项测试，全部通过**：长模拟与环境边界单独运行 2 个文件／20 项，其余 112 个文件／1,497 项单 Worker 运行，覆盖集合无重复或遗漏。初次失败、修复后结果与最终浏览器记录分别保留。规则测试、构建、浏览器报告与发布核对均在本地完成，GitHub Pages 流水线继续只构建与部署。
