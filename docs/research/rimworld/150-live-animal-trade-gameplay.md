# 活畜交易：从商队取得种畜，再接回营地经营

v53 优先接通取得、管理、繁殖和出售的玩法链。价格、供给频率、数量和健康门槛集中配置，留待后续平衡。原版依据见 [149 静态机制](149-live-animal-trade-mechanisms.md)；本文分别说明已经实现的行为和 Web 适配。

## 玩家怎样使用

大宗商品商队现在带着真正的动物从地图边缘进入，第一版供应一对公母鸡和一对羊驼或单峰驼。动物保留自己的步速，沿三维地面路线跟随商队，不能使用居民的垂直梯子。缺少通路或动物容量不足时不会强行生成到营地里。军火商队不提供活畜。

在商队面板安排居民前往交谈，到达后暂停并显示正式报价。物资和每只动物可以放进同一订单；动物显示身份、性别、年龄、生长、健康、饱食、妊娠和产物进度，数量只能选零或一。殖民地可以向大宗商队出售鸡、羊驼和单峰驼；兔和鹿不属于本轮已核对的收购标签。

动物出售不要求位于家园或仓库，但需要商人可接触到、当前仍是殖民地活体，并满足健康与环境条件。野生动物、其它商队的动物、已经离图或死亡的动物不能加入本次报价。地面货物继续使用原有家园或仓储规则。

买入后，地图上的同一只动物留在原地改属殖民地。不会另造一个健康、饱食或产物已重置的副本；原有年龄、成长、伤势、孕期、奶量、毛量和蛋形成进度保留。殖民地接着安排圈地和饲养，可以繁殖、产蛋、挤奶、剪毛或使用自动宰杀策略。新商队不再固定生成受精蛋，真实旧存档商队已经携带的受精蛋仍保留并可买入。

卖出或赠送后，同一只动物改属商队，取消原有照料、牵引、待宰、放归和圈地指派，解除其它动物正在追逐它的配偶任务。已经交到工人手中的饲料仍保留为真实物品。成交动物不会瞬间消失；商队离开时沿实际路线走到地图边缘才移除。商队已经走远但动物被围栏困住时，会显示通路受阻，并在开门后继续尝试离开。

动物面板分开显示殖民地、商队和野生动物。商队动物可以选择检查，不能绕过交易直接驯服、宰杀或放归。回执保存成交时的个体信息；之后再卖回同一只动物、动物离图或死亡，都不会改写旧回执。

## 与已有机制衔接

- **整单原子结算**：先校验报价、个体身份、数量、银币和所有进口货物的落地容量，再同时交付。容量不足、余额不足、重复个体或过期报价都保留原状态；同一会话不能重复成交。
- **独立账目**：银币和材料使用原资源进出口账，动物按物种记买入和卖出次数。活畜不会伪装成尸体 Cargo，也不算新生产的肉。殖民地活畜计入人物类财富，商队活体不计入殖民地财富；市值仍是集中定义的初版值。
- **生活与妊娠**：商队动物会饥饿、觅食、成长和逃离威胁。已有孕体继续妊娠，胎生幼体加入母体当前商队；成交不会重抽孕期。饥饿造成的死亡仍只形成一份尸体并从活畜库存中移除。
- **伤害与离开**：殖民者击中商队动物影响关系，敌对关系使商队撤离。动物与人类分别走出地图；只要还有活畜滞留，所属商队记录继续保留。
- **工作与存档**：转派释放照料和牵引预约，重新启用殖民地正常动物管理。商队访客生成不再继承作为身体模板的居民的蛋箱任务、成品配送任务或允许区域。

## 明确的适配与未完成部分

| 原版机制 | 当前 Web 范围 |
|---|---|
| 物种、温度、市场与数量权重生成库存 | 固定鸡配对，加羊驼或单峰驼配对；动物总数上限沿用 128，供应配置后调 |
| 完整 Pawn 健康、行动能力和季节温度判断 | 简化动物生命值、营养不良和统一温度门槛；不宣称实现完整动物解剖或原版价格链 |
| 商队 Lord、牵引与队形 | 按人类领队位置汇合，真实地面行走；封闭圈栏需要玩家开放通路，未实现商队主动牵引 |
| 胎生后加入母体 Lord | 保留已有妊娠并把新生个体加入母体商队；商队动物暂不主动寻找配偶 |
| 商队母鸡产蛋时记录其派系，孵化不等于自动加入 Lord | 商队鸡的蛋形成进度继续推进，实际产蛋暂缓至买入后；未建立外来地面蛋的完整归属链 |
| 商队动物各自生物产品组件 | 卖出的奶量、毛量原样保留；在本轮已有模型中蓄奶和长毛仍限殖民地动物 |
| 原版商队/据点/轨道交易和驮运载重 | 本轮只实现当前地图大宗商队活畜；其它商人类型、驮货动物载重、远行、动物训练和医疗继续待补 |

## 版本与验证范围

存档升级为 v53。旧存档只增加空的商队动物列表、交易回执动物列表和零值动物账本，不增生任何活畜；已有商人物资、预约日期、蛋箱、孵化批次及工作保持。新存档严格检查活体与商队的一对一归属、跟随目标、路径、殖民地指派冲突和历史快照。历史父代、商队或动物已经离图是合法情况，历史快照不会作为第二个活体注册。

原版核对为静态派生证据：45 个类型、98 处锚点、13 项限定范围检查、16 项 XML 投影。Web 采用受控无界面模型、SSR、旧档逐 tick 对照和生产构建；没有启动原版、浏览器、预览页面或 GUI，也没有把这些检查当成真实画面手感或新营地长局经营验收。
