## 如何复核

本轮已通过本地核验：**112个选定类型的派生文件哈希、133条结论、360处来源引用的结构/行号范围、41组算例（160项数值或结果断言）、29个XML文件中的102处来源引用**，以及经济组22项声明快照、生成组94个XML节点的630个叶值。正文公式还经过交叉复核；这些计数只描述本研究集，不代表覆盖原游戏全部机制。

普通读者不需要原游戏即可检查JSON结构、来源位置范围、相对链接和文中算例：

```sh
npm run research:check
```

该命令运行**分析者编写的公式算例**，不调用 RimWorld、不跑原版随机过程，也不代表Web玩法已经符合原版。它已接入GitHub Actions。算例JSON中的 `formula` 是解释文本，脚本不执行该字符串；真正算式在显式维护的 `case-models.mjs` 中。

食物组另由 `verify-food-evidence.mjs` 校验，已串联进同一 `research:check` 命令；它补充31个类型、19条结论、74处来源引用及9个算例（85断言），复用生成组4个植物类型，不把复用文件重复计为新增类型。本地XML/派生哈希复核入口见12篇。

2026-11-03住房组新增28个类型、22条结论、10个解析算例（141断言），复用6个既有类型；10个XML文件中的25节点/128字段单独核对。`verify-housing-evidence.mjs`也接入同一命令，原版睡眠与门的运行时数值仍未独立测量，详见14章。

同日电力温控组新增31个类型、复用19个类型，25条结论、15个解析算例（186断言）；6个XML文件中的14记录/135字段、24属性节点、24缺省记录分别核对。`verify-energy-evidence.mjs`已串联；实际原版只观察木机信息面板，未测发电和室温动态曲线，见16章。体素实现的191项单元测试与浏览器验证另见17章，不能与原版解析算例混为一项覆盖率。

同日保鲜组新增20个类型、复用5个类型，20条结论、56代码引用和19XML引用；4XML文件/14记录/70叶值，12独立算例120断言与19个破坏拒绝检查通过。`verify-preservation-evidence.mjs`已串联。体素实现共有211项单元测试，正常冷热分支对照与浏览器验收见20章；18章单独记录原版运行，避免混合来源。

18章原版实验保留5份存档摘要、4个区间、7张裁剪和114条UI动作，另有6个温度缓存解码类型。`verify-native-preservation-runtime.mjs`已接入同一命令，`--local`可重读本机存档、原始截图与派生文件。已观察到未冷藏→冷藏→冻结标签，未独立证实全区间持续冻结零增长；开发供电和室外对照失效等限制见18章。

同日物流组新增8个类型、复用14个，18条结论、39代码引用和24XML引用；9XML文件/23节点/60叶值，11组独立案例103断言和23项篡改拒绝检查通过。`verify-logistics-evidence.mjs`已串联。原版实测另保留2份存档摘要、7张裁剪和52条动作，`verify-logistics-runtime.mjs`核对71+4+75守恒及未证实边界。体素当前237项单元测试、12组正常物流检查及两种渲染的浏览器检查见23章。

有相同版本安装与相同ILSpy库时，可在项目目录执行（路径按本机实际位置填写）：

```powershell
$gamePath = 'F:\SteamLibrary\steamapps\common\RimWorld'
$decompilerPath = 'C:\path\to\ICSharpCode.Decompiler.dll'
foreach ($group in @('work','combat','environment','economy','generation')) {
    ./scripts/research/extract-rimworld.ps1 -GameRoot $gamePath -DecompilerPath $decompilerPath -Group $group
}
./scripts/research/verify-local-sources.ps1 -GameRoot $gamePath
./scripts/research/verify-generation-evidence.ps1 -GameRoot $gamePath
```

综合工作区已有分析库路径是 `tools/ilspy/lib/netstandard2.0/ICSharpCode.Decompiler.dll`（相对综合工作区根目录）；独立Emberfield仓库不附带该库。提取器检查原程序集与工具哈希，按UTF-8无BOM、LF输出，以保证来源行号可复现。版本不同应另建版本证据集，不能沿用旧行号与算例结论。

`verify-local-sources.ps1` 检查原程序集哈希、派生文件哈希与行数、引用XML哈希及XPath存在性，并校验经济组22项XML声明快照。**XPath命中与哈希一致不自动证明文字解释正确**，语义仍需人工复核。环境、工作、战斗的XML值记录在各自结论账本中。

## 后续研究入口

有限地面仓位与物品堆叠已在23章接入；后续补货架/容器、岩块切石链，再扩展世界生成/资源分布与健康、战斗模块。原版研究仍需继续仓储合堆/满75/扩容的受控复测、门与通风动态实验、身体部位受击与近战、生产账单与品质/失败、完整市值与贸易提交、招募/社交/关系。原版资料与 Emberfield 数值保持分开，避免将当前实现误称为原版全部机制。
