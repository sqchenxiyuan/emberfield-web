# 99 居民交往与桌边休闲

本轮补上居民日常交往的闭环：玩家布置桌椅和共同作息，居民实际到场休闲，附近合适的人发生即时互动，互动留下有方向的人际意见或独立的心情记忆。玩法、预约和存档连续性优先；互动节奏、娱乐增益、家具经济与长期关系平衡仍可调整。

原版派生机制见[97](97-social-interaction-mechanisms.md)，原版实机观察及准备边界见[98](98-native-social-runtime.md)。这三类内容分别描述原版静态规则、观察到的执行和本项目实现，不互相替代。

## 玩家操作

1. 建一张木餐桌，并在同层四邻放真实餐椅，留出步行路线。桌子详情中的“允许聚会”默认开启。
2. 给居民安排重叠的娱乐作息。他们会根据需求、同类娱乐耐受和可达位置选择活动；空闲椅子不足时选择其他活动。也能在人物详情明确选择桌边休闲，但仍需实际走到座位。
3. 到座后持续恢复娱乐并获得座椅舒适；独处也能休闲，不要求先有同伴或酒。附近居民满足条件时会自然交谈，桌边休闲使互动更常见。
4. 人物详情显示“我对对方”和“对方对我”两种意见；展开可看具体来源、当前影响和剩余时间。侮辱的意见与心情分开显示，最近互动记录发起者与接收者。
5. 关闭聚会会取消正在前往或进行的桌边休闲，已有用餐继续。征召、取消、拆除和火毁家具会释放休闲座位；存档可保留旅途、座位预约和关系状态。

## 持续休闲与即时交谈

桌边休闲是有目标、路径、预约和结束时刻的持续任务。闲聊、深入交谈和侮辱则在一个模拟时刻结算：保留原工作、货物和路径，不生成一个虚假的长时间聊天任务。人物头上的短暂气泡来自真实的权威事件，按模拟时间消退；暂停时不会继续老化，读档后的过期日志不会重新冒泡。

吃饭与桌边休闲共用座位预约，先预约者先用。已有休闲者不会被后来用餐者抢走椅子，后者寻找其他座位或按原来的无座用餐流程进食；已有用餐者也不会被后来休闲者抢位。一张桌子可以容纳多名使用不同餐椅的居民。桌边吃饭允许站立的既有规则不等于桌边休闲可以没有椅子。

当前只自动发生殖民者之间的普通互动。人物必须清醒、可行动、不被搬运，也不能处于征召、战斗、护理、看守、交易、驯养、牵引或灭火等排他活动。口语能力决定能否主动发起；听觉参与影响幅度，不额外冒充接收门槛。三维距离与视线共同限制交谈，墙、关闭的门和中间楼板会阻挡，桌面本身不按墙处理。

## 关系、记忆与心情

| 状态 | 规则 |
| --- | --- |
| 闲聊 | 双方分别增加对对方的累计意见；同对象一条累计，不因新闲聊重置原衰减时钟。累计值可以超过显示上限，按游戏日逐步减少 |
| 深入交谈 | 双方分别保留来源事件；前段保持完整影响，后段逐渐淡出，同类记忆有叠加衰减与数量上限 |
| 侮辱 | 接收者留下对发起者的负面意见，并另外获得期限较短的心情记忆；发起者不自动得到同样的记忆 |
| 历史幅度 | 互动发生时按对方的社交能力确定幅度并保存；之后技能升级不追改旧记忆 |
| 方向 | A 对 B 与 B 对 A 单独计算；不会把两者合并成一个共同关系分数 |
| 离图身份 | 仍被记忆或日志引用的人只保留小型身份记录，不能被物品、装备或后来的人冒用；失去所有引用后移除 |

正面交谈本身不额外发放通用心情奖励。休闲的娱乐需求改善可以通过既有心情规则产生反馈，与“交谈直接加心情”有区别。

## 保存与运行开销

v32保存每人的下一次尝试时刻、互动意愿、上次互动时间和记忆，并保存有界的全局事件及离图身份。随机抽取由种子、人物、模拟时刻和用途决定，不依赖渲染帧或未保存的随机游标。旅途中回读重新验证桌椅与路线，座位冲突或无效引用不会悄悄被接受。

旧v31及更早存档升级时保留原生活状态、食物批次和用餐进度，添加空关系状态、零社交娱乐耐受和默认开启的聚会开关，不补发历史交谈。招募保留同一人物的关系；新生成商队成员会创建独立状态，不继承用于生成外观模板的殖民者记忆。

每人至多64条社交记忆，最近事件至多64条；离图身份只随仍在引用的记录存在。候选扫描以最多64名人物为上界，只有到期的互动尝试才检查近邻和视线，没有新增整张地图的每帧扫描，也不复制完整离图人物。

## 有意保留的实现边界

- 原版普通社交默认模式由Job和Toil决定；本轮Web把普通行走/劳动/空闲统一设为Quiet、持续的普通娱乐/用餐设为Normal，到座桌边休闲设为SuperActive。只有稳定生活任务才提高互动频率，读档重排普通工作时的暂时空闲不会提高概率。征召与专门任务的排除也是本项目策略，不能写成原版全部规则。
- 原版是平面距离与视线；本项目扩展为三维距离、墙体/楼板/门阻挡。调度与概率按当前游戏日比例换算，Web继续20 TPS、12,000 tick/天，渲染频率独立。
- 当前没有人物年龄和性格形成的兼容度模型，兼容度暂取中性。技能、说话及听觉能力参与社交影响；亲属、恋爱、婚姻、完整性格、社交打架、侮辱导致的其他精神状态尚未实现。
- 同类侮辱心情达到容量时，Web替换最旧条目并记录本次真实施辱者；原版普通记忆合并可能刷新旧条目的年龄并保留旧来源。这里优先保证检查界面的来源可信。
- 只提供木餐桌聚会，不包含篝火、饮酒、聚会事件或完整娱乐室评价；休闲结束时的原版娱乐室印象记忆尚未接入。
- 少量普通经营观察能证明流程可达，不能证明所有概率、稀有互动和长期社会生态已完成校准。

## 验证

```sh
npm test
npm run build
npm run test:voxel:social
npm run test:voxel:social:browser
npm run research:social
```

局部测试覆盖累计/淡出、方向、心情区别、视线、排他状态、座位竞争、中断、真实v31迁移、离图身份及存读继续。普通经营从未经编辑的新开局，经实际伐木与桌椅/床施工、共同作息走到自然交谈；浏览器验收分别运行Worker与主线程模式，以可见控件操作并检查画面和来源信息。最终运行清单、源码与构建身份记录在[验证证据](evidence/voxel-social-validation.json)。

本地覆盖共1078项测试、81个文件。全量并发运行中，旧食品测试的八日真实收获准备超过180秒墙钟门槛，留下9项未执行；该文件随后独立重跑17项全部通过（包括这9项），原始两次报告与覆盖汇总均保留，没有把未执行项计作通过。

最终普通经营验证通过26项检查，在第5301 tick完成；Worker与主线程渲染模式各通过15项浏览器检查，没有页面或控制台错误，实际加载的JS/CSS与本地最终构建哈希一致。验证包括真实到座、双向意见与来源期限、气泡暂停和过期、导入导出、手动选择后的实际行走、聚会开关与用餐延续，以及900像素宽界面。普通经营自然观察到了闲聊，深入交谈、侮辱和长期记忆分支另由机制测试覆盖。

测试均在本地执行，Pages只安装依赖、检查类型、构建与部署。
