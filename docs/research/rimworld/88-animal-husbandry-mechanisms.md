# 动物驯养、营养与繁殖机制

本章基于本地 **RimWorld 1.7.4980 rev60** 的程序集、Core XML 和一轮原生驯服实验，补全“野生动物 → 家畜 → 进食与维护 → 繁殖与成长”的机制。Web 实现及主动简化见[90：动物驯养玩法](90-animal-husbandry-gameplay.md)，原生操作与存档见[89：原生驯服实验](89-native-animal-husbandry-runtime.md)。

## 1. 驯服是一项有真实成本的现场工作

`Designator_Tame` 先删除目标现有的指定，再添加 `Tame`，因此新驯服标记会清掉已有狩猎标记。是否可驯服与能否开始工作分开检查：动物或野人、非人类阵营归属、野性小于 1、非树精且没有 Scaria，才进入候选；实际驯养员还要满足预约、动物技能、目标未倒地、清醒且能够交互等条件。普通优先工作命令仍经过技能和冷却检查。来源：AH01–AH02。

原版最短再次尝试间隔为 **30,000 ticks = 0.5 游戏日**，比较的是动物 `lastAssignedInteractTime`。这不是整个驯服任务的固定时长，也不是每天最多两次的硬配额。移动、寻找可交互位置、等待和工作中断都会影响实际完成时间。

任务链为：

```text
指定驯服 → 检查资格与冷却 → 检查携带食物
  → 不足时找食物、走过去并拿进物品栏
  → 接近动物 → 三段交流，穿插两轮喂食
  → 记录交互时间 → 最终成功抽签
  → 成功：更换阵营、命名、清除指定、初始化驯顺
  → 失败：仍是野生动物；可能触发该种属的狂暴反击
```

失败不会累计一个必然成功的“驯服百分比”。不要沿用[人类囚犯抵抗值](73-prisoner-recruitment-mechanisms.md)的模型：人类招募与动物驯服虽共用部分交互代码，动物分支使用单次成功概率。来源：AH05–AH06。

### 饲料数量与交互时长

设动物当前最大食物容量为 `M`，单轮目标营养为：

```text
Nfeed = min(M × 0.15, 0.3)
一次尝试包含两轮喂食。
Tame 补给目标 = Nfeed × 2 × 4
Tame 拿取数量 = ceil(补给目标 / 单份营养)
```

原版准备的是四次尝试的营养量；现有物品栏检查只需能支持本次两轮。地图搜索排除站立植物、药物、尸体、营养膏机、禁用物和社会规则不允许的食物，并要求动物能吃、食物偏好等级不超过 `RawTasty`。这与动物自主吃草的搜索规则不同。来源：AH03。

每次喂食都真实执行“物品栏取出 → 携带 → 动物摄入 → 剩余放回物品栏”。喂食份数用 `StackCountForNutrition` 的四舍五入且至少一份；`Tame` 初次拿取使用向上取整。共享的训练补给函数又使用前者，不能把所有取整位置合并成一个公式。来源：AH03–AH04。

三段交流各有 `270 ticks` 延迟；喂食使用 `ceil(270 × 实际拿出份量的营养 / Nfeed)`，可能因食物不连续而拆成多段。因此 `270` 不是一次驯服总耗时，`3×270+2×270` 也不是所有动物通用的完成时间。路径、等待和份量取整还会改变总耗时。

原生实验中的米每份营养为 **0.05**，继承 `PlantFoodRawBase`。普通任务从地面 75 份拿走 5 份，尝试完成后物品栏由 5 变为 3，地面保持 70；这与实际喂食链路一致。截屏与存档证明的是前后两份消耗，没有逐帧记录每一轮喂食完成的瞬间。

### 成功率与技能门槛

普通动物尝试的核心是：

```text
p = handler.TameAnimalChance × F(wildness) × 条件修正
F 的节点：(0, 2)、(0.5, 1)、(1, 0)
```

Core 的 `TameAnimalChance` 默认基础值为 1、最低值 0.01，动物技能因子为 `0.04 + 0.03 × 等级`；讲话、听力、操作能力和完整 Stat 处理还会影响最终值。与目标已有羁绊时乘 4，符合崇拜动物条件时乘 2；野人囚犯分支还有 0.6 因子。不能只用技能公式就声称算出了某一受伤角色的实际概率。来源：AH05、AX01。

最低操作技能另用野性曲线 `(0,0)、(0.15,1)、(0.98,10)、(0.99,14)` 插值并取整。野兔和鹿的普通野性为 **0.75**，最低 Animals 等级是 **8**；门槛与成功概率是两件事。来源：AH21。

`Inspired_Taming` 在最终检查中把概率设为 1 并消耗灵感。本轮通过开发者菜单授予了该灵感，因此只验证普通成功转变，**没有测量自然成功率**。失败后的狂暴由物种 `manhunterOnTameFailChance` 等条件控制；不能给所有动物套同一个反击概率。

## 2. 家畜依赖可达食物和有限植物

动物的自主进食仍经过食物需求、食性、禁用/可达性等检查。普通野兔与鹿属于 `VegetarianRoughAnimal`，支持生植物类食物和站立植物；不是所有动物都能吃草，也不是所有驯服饲料都能用任何植物代替。所选草食动物食物低于 **45%** 时自主寻找食物，Hungry 和 UrgentlyHungry 阈值分别为 **36% / 18%**，到 0 才是 Starving。来源：AH07。

吃草调用植物自身的摄入计算：

```text
可用营养 = 当前 growth × 植物 Nutrition
摄入营养 = min(想吃的营养, 可用营养)
部分吃掉：growth -= 摄入营养 / 植物 Nutrition
全部吃掉：消费整个植物，进入销毁流程
```

Core `Plant_Grass` 的满生长 Nutrition 为 **0.50**、`growDays = 2.5`。植物生长仍受光照、温度、肥力等规则影响，不能解释成任何条件下两天半必然恢复。原版被吃光的植物也不等于“这个格子永远自动补草”；植物生成/再生链见[30：植物生命周期](30-plants-lifecycle-forestry-regrowth.md)。来源：AH08。

食物需求基础消耗为 `lifeStage.hungerRateFactor × race.baseHungerRate × 2.6666667e-5 / tick`，还乘当前饥饿分类、健康、特性、床等修正。成年且处于 Fed、无其他修正时，野兔约 **0.184 营养/日**，鹿约 **0.32 营养/日**。XML 中 `0.115 / 0.2` 是基础系数，不能直接标成每天吃掉的营养。来源：AH10。

## 3. 野兔与鹿的管理方式不同

| Core 普通种属参数 | 野兔 Hare | 鹿 Deer |
|---|---:|---:|
| 野性 / 最低动物技能 | 0.75 / 8 | 0.75 / 8 |
| 基础体型 / 基础饥饿系数 | 0.2 / 0.115 | 1.2 / 0.2 |
| 食性 / 基础可训练性 | VegetarianRoughAnimal / None | 同左 |
| 圈养方式 | 允许活动区域 | 围栏、围栏标记与牵引 |
| `roamMtbDays` | 所选继承链未设置 | 2 |
| 驯顺维护 | 会退化 | 普通围栏动物豁免驯顺退化 |
| `mateMtbHours` | 8 | 默认 12 |
| `gestationPeriodDays` | 5.661 | 5.661 |
| 幼年阈值 | 0.1 年，即 6 个足量成长日 | 同左 |
| 成年阈值 | 0.2222 年，即约 13.332 个足量成长日 | 0.3333 年，即约 19.998 个足量成长日 |
| 一窝数量 | 曲线抽样取整，1–2 只 | 未设置曲线，默认 1 只 |

`roamMtbDays` 使鹿成为 `Roamer/FenceBlocked` 并走牵引管理；野兔没有这个属性，普通围栏不能把它当鹿一样约束。允许区域是行为管理，并不是实体墙。驯服工作成功后可能继续生成牵到合适围栏的工作，找不到则提示；系统不会替玩家建围栏。来源：AH06、AH10–AH11。

`trainability=None` 不会阻止 Tameness，但不提供搬运、救援、服从和攻击训练。训练工作需要相同阵营、可训练项目、合格驯养员、真实饲料，并使用 **15,000 ticks = 0.25 日** 交互冷却。来源：AH09、AH21。

Tameness 有 **5 步**。退化间隔由野性 0→12 日、1→6 日线性插值；0.75 对应 **每次 7.5 日**。Tracker 从有步数且不作为其他已学项目先决条件的项目中选择一个退化，不能把“每次减一步”解释为同时损失所有技能。普通野兔只需看驯顺链；降至 0 后玩家动物回到无阵营。鹿属于 `FenceBlocked`，跳过驯顺退化。来源：AH20。

## 4. 繁殖需要到场互动，并受食物约束

`Animal` 思考树将普通交配放在 `HasFaction` 分支中。这不支持“地图所有野生动物一直按同样规则繁殖”的推断。非不育雄性发起，在可达的 30 格内寻找相同阵营、同种或明确允许杂交的可育雌性；目标不能倒地、禁用或忙于无法随意中断的行为。未达到繁殖阶段、已怀孕和阻止怀孕的健康状态都会被过滤。来源：AH14。

`mateMtbHours` 是机会频度参数；成功找到配偶后仍要走到接触距离、等待 **500 ticks** 才调用 `Mated`。普通哺乳动物此时以 **50%** 条件抽签建立孕期。这不代表每 8/12 小时必定受孕，也不能跳过交配距离在 UI 中直接推进怀孕。来源：AH15。

怀孕进度用 Hediff severity 保存，初始 **0.001**：

```text
进度增量 = 饥饿倍率 × deltaTicks / (gestationPeriodDays × 60000)
Fed: 1；Hungry: 0.5；UrgentlyHungry: 0.25；Starving: 0
```

两种动物名义孕期参数均为 5.661 日；由于从 0.001 开始及 tick 检查粒度，不能再把这个参数写成从受孕到出生精确到 tick 的实测值。进度达到 1 时动物直接生成幼体，未走人类分娩流程。幼体沿用母亲种类和阵营、从零年龄生成，继承活动区域并添加父母关系；普通生成器处理性别及玩家动物驯顺初始化。来源：AH16–AH17。

幼体有独立 `growth`，成长和孕期共用上述营养倍率。生物年龄仍按时间增加；饥荒暂停的是成长进度，不是生日。原版一生物年为 **3,600,000 ticks = 60 日**，所以表中成年时间应理解为食物充足情况下累积的成长时间。来源：AH12。

| 生命阶段 | 体型因子 | 食物上限因子 | 健康因子 | 饥饿率因子 | 可繁殖 |
|---|---:|---:|---:|---:|---|
| AnimalBaby | 0.2 | 3 | 0.25 | 0.4 | 否 |
| AnimalJuvenile | 0.5 | 1.5 | 0.6 | 0.75 | 否 |
| AnimalAdult | 1 | 1 | 1 | 1 | 是 |

食物上限因子还与体型和完整 MaxNutrition Stat 共同作用，不能把“Baby 的 3”单独解释成幼崽容量是成年三倍。来源：AH13、AX03。

### 营养不良和流产

需求每 **150 ticks** 更新。Starving 时增加、进食后逐渐减少 Malnutrition，幅度为 `0.0011325 × 个体固定的 0.8–1.2 系数`，基础每天严重度变化 **0.453**。严重度 0.8 时意识上限 0.1，严重度 1 致死。重新吃到一口食物不会立即清掉已有营养不良。来源：AH19。

孕期每 **1,000 ticks** 检查风险：Starving 且 Malnutrition >0.1，以 **MTB 2 日** 检查流产；严重伤情总量高于 `38 × baseHealthScale` 还会独立检查相同 MTB 风险。流产移除孕期。这是随机风险，不能改写成“断粮两天必流产”的固定倒计时。来源：AH18。

## 5. 对 Web 复刻的约束

优先保留真实因果关系：食物有位置与数量，取食占用行走和工作时间；动物有稳定身份、阵营、生命阶段与孕期；交配必须实际接触；取消工作只能归还未消耗的饲料；饥饿通过营养不良及成长变化影响经营。

可以主动压缩时间并集中调参，但要和原版值分开。当前 Web 的两日孕期、四日成年、每窝一只，以及流产阈值、取粮量和冷却等适配均记录在[90](90-animal-husbandry-gameplay.md)，不能据此宣称还原原版平衡。完整围栏/牵引、活动区域、训练项目、畜产品和动物医疗是独立后续任务。
