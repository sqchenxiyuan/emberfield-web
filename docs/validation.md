# 首版范围与验证

记录日期：2026-11-02。

本项目是独立实现的殖民地模拟首版：96×96单地图、3名初始人物、18种建筑、9类工作、6项研究。生产、建设、种植、烹饪、生活需求、心情、战斗、救援医疗、电力、研究、撤离与继续经营形成可玩的循环。详细操作见 [README](../README.md)。

这是有限范围的首版，不包含完整RimWorld/Core/DLC内容。招募、贸易与派系、狩猎驯养、感染免疫、完整社交、房间/屋顶/温度/火灾、装备制造、多地图、多人和Mod兼容尚未实现。

## 已有验证

- 22项模拟规则测试：固定步长确定性、材料与预定、生产、寻路阻挡、任务中断、医疗、电网、结局、继续经营，以及中途存读档严格一致。
- 23项浏览器检查：实际建造、区域拖拽、征召与指令、IndexedDB、20次读档、刷新后恢复、损坏存档拒绝、JSON导出、人物详情标签、HUD布局、镜头、胜利后继续以及渲染回退。
- 实测渲染路径：WebGPU Worker、WebGL Worker、主线程WebGL。
- 默认种子73129从初始物资以正常玩家命令经营10个完整游戏日，3人撤离成功；没有直接添加资源、完成建筑或改写战斗结果。
- 10个固定种子的同一经营策略得到9次撤离成功、1次战斗失败；失败种子为12345，约第9.7日。这不是通用胜率或成熟平衡保证。
- UI视口检查：1440×1000、1280×800、1024×720、720×720。窄桌面窗口检查不代表手机触控适配已完成。

UI采用地图主体、顶部人物、左侧资源、底部操作、左下检查窗、右下时间控制。人物详情分状态/健康/技能，分工表以人物为行、岗位为列。

## 性能记录的范围

首版较早构建在i7-4790K、RTX 2060 SUPER、约32GiB RAM、Chrome 154环境测量。真实第8日营地的6倍速短采样约121TPS / 60FPS；之后5分钟以模拟暂停、渲染和镜头操作继续的方式采样，渲染进程合计私有提交约192–258MiB，整个独立Chrome进程组约510–819MiB。

该记录早于最后的方向键、继续经营和HUD布局调整，不是发布构建重新测得的内存保证。私有提交不等于独占物理内存或显存；尚未验证4GiB物理内存设备、百人殖民地、大地图、完整显存占用或60分钟活跃模拟稳态。

## 复现

```sh
npm ci
npm test
npm run test:campaign
npm run test:seeds
npm run test:performance
npm run build
npm run preview
```

保持预览服务器运行，在另一终端执行 `npm run test:browser`；脚本需要本机安装Chrome。浏览器测试依赖campaign脚本生成的第8日与撤离存档，结果写入不提交的 `test-results/`。

`npm run test:memory` 默认进行5分钟短测，Windows下通过CDP识别本次Chrome进程并读取进程内存；其他系统没有对应的完整进程内存读数。

线上检查可设置 `COLONY_TEST_URL=https://sqchenxiyuan.github.io/emberfield-web` 后运行 `npm run test:browser`。该脚本在独立浏览器上下文中操作，不会使用玩家当前浏览器的存档。
